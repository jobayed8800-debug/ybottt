## 🔓 User Flow

1. User starts bot with `/start`
2. Clicks "🔓 Unlock 24H"
3. Gets unique ad link
4. Watches ad for 10 seconds
5. Clicks unlock button
6. Gets confirmation code
7. Enters code in bot
8. Gets 24-hour access
9. Can view tournaments and complete tasks

## 🛡️ Tournament Rules

- Squad members must have same first name
- All members must be level 40+
- All members must be in same guild
- No cheats/hacks allowed
- One hacker = whole squad banned
